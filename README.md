## What it's built with

- [TanStack Start](https://tanstack.com/start) (React 19 + TanStack Router), TypeScript
- Vite, Tailwind CSS 4
- Animation is hand-written: SVG paths for the threads, `requestAnimationFrame` for the scroll story, CSS for reveals. No animation libraries.
- Can be deployed on [Vercel](https://vercel.com)

## Where things live

- `src/routes/index.tsx`: the home page (story, work, ending)
- `src/routes/work.tsx`: all the work, reached by falling down the rabbit hole
- `src/components/rabbit-hole.tsx`: the fall and the climb back out
- `src/styles.css`: theme tokens and animations
- `src/assets/`: the 3D objects, project screenshots and profile image

## Run it locally

```sh
npm install   # or bun install
npm run dev   # or bun run dev
```

Visit `http://localhost:3000` to see the portfolio.

## Build for production

```sh
npm run build
npm run preview  # to preview the build locally
```

## Customization

This portfolio template was originally created by [Nidhi Prajapati](https://github.com/SomehowLiving) and customized for my personal use. The code is [MIT-licensed](LICENSE).

To customize it for yourself:

1. Update personal information in `src/lib/seo.ts`
2. Replace projects in `src/routes/index.tsx` and `src/routes/work.tsx`
3. Add your images to `src/assets/` (profile photo and project screenshots)
4. Update the story content in `src/routes/index.tsx` to match your personality
5. Customize colors in `src/styles.css` if desired
